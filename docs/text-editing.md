# 文本编辑与内容保护 · v0.7.0

顶部「文本编辑」面板保留选择、复制、剪切、粘贴和剪贴板，新增退格、撤回与翻译。再点同一导航图标关闭。按住退格连续删除；抬手、移出按钮、隐藏键盘或切换面板即停止。

## 撤回

记录当前输入框内由轻语产生的输入、删除、剪切、粘贴、替换和翻译修改，按顺序逐步撤回。拼音候选上屏作为一次修改，撤回不会重新插入原始拼音。只保存内存中的文本差量，不记录到磁盘或上传。切换输入框结束会话后清空。

每次撤回先校验输入框完整文本，外部应用改动使旧历史失效；单独移动光标不会破坏历史。宿主不能提供完整文本时不执行不安全的撤回或翻译替换。保留最多 256 步、约 512 KiB 文本差量；输入框超过 65,536 个 UTF-16 单元时停止记录。密码框不提取历史、不翻译、不启用剪贴板功能，仍可移动光标和退格。

## 翻译

- 未选择文字：翻译整个输入框中的中文，保留外语与其他内容。
- 选择中文或中外混合内容：只翻译选区中的中文，保留选区之外的内容和外语。
- 选择纯外语：端侧识别语言；对应模型已安装且识别可信时翻译为中文。识别不确定、模型缺失或失败时保留原文，不自动下载。
- 成功后替换原范围，可以撤回；等待期间输入内容、选区、语言或输入框变化，不应用旧结果。

中文使用当前选择的英语、日语、法语、德语、俄语或西班牙语。优先本地中英词典，缺词时使用已下载的端侧模型。推理独立于输入线程，输入法候选不等待编辑翻译。

原有标点、数字、Emoji、换行、空白、链接、邮箱及可识别的代码片段原样保留。含假名的连续日语片段在中文翻译中整体保留。每次请求上限 4,096 个 UTF-16 单元、64 个可翻译片段、45 秒；全部片段成功才替换，取消后不再继续后续片段。正在执行的共用模型任务不强制中断，迟到结果失效。

为严格保留原空白和标点，外语按文字片段翻译并重新拼接，句子自然度可能受限。极短外语、共用汉字以及没有分隔的中日混合内容不能保证识别准确；无法可靠区分的含假名片段优先保留。模型输出也可能不准确。
