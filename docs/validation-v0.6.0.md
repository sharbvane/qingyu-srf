# 轻语输入法 v0.6.0 验证记录

记录日期：2026-10-08。基于 v0.5 项目迭代；正式 APK 已完成构建、审计、保留数据覆盖升级及实际键盘回归。下文区分原生候选测试、宿主微基准、Debug 专项和最终 Release，不将不同构建的通过项相加。

## 本轮行为与来源

- 中文全拼使用「分词」键插入拼音分隔，英文保留 Shift；回车提交原始拼音。
- AOSP 原生解码与已有现代词库继续工作，新增有界中文上下文统计，改进连续拼音组词、可靠预测及个性化排序。已有三个学习文件保留，纠错仅追加可选候选。
- 本地释义优先，已安装端侧模型异步补充当前语言；上滑输入简洁译文，长按查看词性、完整释义、可追溯例句及来源。普通候选和展开列表不显示 `powered by Google Translate`，详情保留模型来源。官方归属要求与本次 UI 范围的差异见 [SDK 来源说明](../third_party/mlkit/SOURCE.md#attribution)。
- 展开列表纵向浏览，长句与翻译完整换行；短候选栏不随翻译改变候选宽度。
- 模型管理显示实际字节/总量、等待与失败状态；未知总量使用不定进度，重试与删除保留。默认 Wi-Fi，移动数据须用户明确允许；普通打字不触发模型下载。

上下文资源来自 [UD Chinese GSDSimp r2.18](../third_party/input-data/chinese-context/SOURCE.md)，固定提交 `7b61ed473f963e911788efdf1f478154bc1053e4`。只用 TRAIN 的 3,997 句 / 98,614 token；DEV/TEST 不参与统计或例句。源 `.bin.gz` 资源 2,736,395 字节，SHA-256 `4c748464c3097bf84084b3f35d29af6d627d1be93873e8aa42472a7864bcd763`；AAPT 将其展开为 APK 内 3,494,939 字节的 `.bin`，最终运行时使用未压缩数据解析器，审计逐字节比对源资源解压结果。上游 CC BY-SA 4.0、作者与底层文本权利声明随 APK 保留；[精确来源及变换](../third_party/input-data/chinese-context/manifest.json)。[来源检查](chinese-context-source-results.txt)已验证 1,207 词对应的例句均为精确 TRAIN 摘录，未知/标点预测为空、损坏资源被拒绝；加载器自检覆盖 gzip/展开数据等价读取。没有合适例句时不虚构内容。

另一次 Debug 交互运行已通过前面的候选/导航布局检查，随后旧版预测断言仍期望“中国 → 人”，实际为“人民”。该次整体运行未通过，不能把前面部分通过项称为完整 IME 验收。

## 尚未验证与已知边界

未连接物理手机，未完成 OEM/富文本应用、16 KiB ARM64 实机、长期内存与功耗、触控帧时延、震动和单手手感的测量。API 35 模拟器、宿主检查与构建成功不代表这些场景已验证。官方模型 SDK 的 ARM64 页对齐限制保留安全降级：16 KiB ARM64 设备暂时禁用模型下载/翻译，中文输入及本地中英释义继续工作，设置说明限制。

连续拼音使用有界搜索、有限语料统计而非完整语言理解，百科 DEV 难句仍有覆盖和排序缺口；原始拼音始终保留，分词键与分段选择可用。真实模型服务需要可访问官方服务器，离线且未下载时无法提供相应语言译文。后续网络覆盖更新必须等真实更高版本可供下载后验收。
