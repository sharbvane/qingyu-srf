# 轻语 Qingyu v0.2.0 · Android 输入体验更新

轻语仍以中文输入为先。v0.2.0 加入九键中文、英文候选与上下文预测，并可在候选上方显示释义。轻点输入原词，长按阅读完整释义，上滑输入译文。新候选栏、更多/编辑/Emoji 面板、100 条剪贴板记录、连续键盘高度和三种释义语言完善了日常使用。

### 验证

- 同一 Release APK 通过 17 项基础输入回归和 26 项新增交互检查；下载模型后的候选流程也通过 26 项检查。
- Google ML Kit 的英、日、法模型已实际下载。词典之外的中文整句完成中译英、日、法；英文整句完成英译中。再关闭 Wi-Fi 和移动数据，四个方向的整句译文仍可离线产生。
- APK 签名、三 ABI、ZIP 对齐、自有原生库、词典、来源与第三方许可已核验。

- 大小：61,859,382 字节（58.99 MiB）。
- SHA-256：`29B11C99EF6E31A45E2CDFBE650D58161C8060DE0D26E66C89188C0E0A919801`；旁附 `.apk.sha256` 文件。
- 与 v0.1.0 使用相同体验签名，可覆盖安装。

常用词与短语释义无需联网。更广的句子翻译需从「更多 → 释义显示语言」通过 Wi-Fi 下载 Google 离线模型；模型不预装在 APK 中。Google SDK 会发送安装/设备、语言、文本长度和性能等元数据，不发送输入或译文原文，详情见[隐私与 SDK 说明](../../third_party/mlkit/SOURCE.md)。

Android 15 / x86_64 模拟器的输入与模型检查见[验证记录](../validation-v0.2.0.md)。真机手感、功耗、帧率、OEM 输入框兼容性及长时间稳定性仍待体验验证。

# Qingyu v0.2.0 · Android typing update

Chinese input stays first. This release adds Chinese T9, English completions and context predictions, subtle candidate glosses, and tap/hold/up-swipe candidate actions. The simplified More, Edit and Emoji panels include clipboard history for the latest 100 items, a continuous keyboard-height slider, and English/Japanese/French gloss settings.

### Validation

- The Release APK passed 17 baseline input checks and 26 new interaction checks. The downloaded-model candidate flow passed the same 26 checks.
- English, Japanese and French ML Kit models downloaded successfully. Unlisted Chinese sentences translated to all three languages, and an English sentence translated into Chinese. All four directions still produced full-sentence translations after Wi-Fi and mobile data were disabled.
- APK signing, three ABIs, ZIP alignment, native libraries, dictionaries, provenance and license notices were verified.

### Download

- `Qingyu-0.2.0.apk`, Android 8.0+, arm64-v8a / armeabi-v7a / x86_64.
- Size: 61,859,382 bytes (58.99 MiB).
- SHA-256: `29B11C99EF6E31A45E2CDFBE650D58161C8060DE0D26E66C89188C0E0A919801`; a matching `.apk.sha256` file is included.
- Signed with the same preview key as v0.1.0; existing installations can be upgraded in place.

Common glosses and phrases work offline. Full-sentence translation requires downloading Google on-device models over Wi-Fi from More → Gloss language. Models are not bundled in the APK. Google SDK metadata disclosures are documented in the [SDK privacy notes](../../third_party/mlkit/SOURCE.md); typed text and translations are not sent to Google.

**16 KiB ARM64 limitation:** The current official model library has an ARM64 RELRO end that is not aligned to 16 KiB pages. This release disables model downloads and inference in 64-bit ARM processes with pages larger than 4 KiB. Pinyin, local glosses and bundled three-language phrases remain available. An affected physical device has not been tested.

See the [validation log](../validation-v0.2.0.md) for Android 15 x86_64 emulator results. Physical-device feel, power, frame rate, OEM editor compatibility and long-term stability still need field testing.
