# 轻语 Qingyu v0.1.0 · 首个公开版本 / First public release

## 中文

轻语是一款可安装为 Android 系统输入法的中文全拼键盘。输入中文时，候选上方会显示本地英文词典释义；点击候选只提交中文。释义查找不参与候选排序，翻译关闭、缺词或查询失败都不会阻塞输入。

### 核心功能

- AOSP PinyinIME 原生解码器、整句及分段选词、候选展开与翻页。
- 中文标点、英文/数字/符号及中英混输。
- 连续退格、长按数字、空格滑动光标、候选横向浏览。
- 深浅主题、键盘高度、震动、按键预览和本地词频开关。
- 随包离线 CC-CEDICT 英文词典；可独立关闭释义。

### 测试情况

最终 Release 包在 Android 15 / x86_64 模拟器上通过 17 项系统输入自动化检查，涵盖候选只提交中文、横竖屏、快速中英数字混输、连续删除、密码输入、数字键盘与深色模式。APK 的 v2 签名、16 KB 对齐、arm64-v8a / armeabi-v7a / x86_64 ABI、词典与第三方声明均已核验。

**真机长时间使用、厂商输入框兼容性、FPS、功耗及现代词库准确率尚未验证。** 此包用于公开体验，使用 Android 开发签名；正式稳定发行前需配置专用密钥。

## English

Qingyu is an installable Android full-pinyin keyboard with quiet, local English dictionary glosses above Chinese candidates. Tapping a candidate commits Chinese only. Translation does not rank candidates or block typing when disabled, missing or unavailable.

### Highlights

- AOSP PinyinIME native decoding, sentence and segmented candidates, candidate expansion and paging.
- Chinese punctuation, English, numbers, symbols and mixed input.
- Repeat backspace, long-press numbers, spacebar cursor movement and horizontal candidate browsing.
- Light/dark themes, keyboard height, haptics, key preview and local user-frequency controls.
- Bundled offline CC-CEDICT English dictionary with an independent gloss toggle.

### Validation and known limits

The final release APK passed 17 automated system-input checks on an Android 15 / x86_64 emulator. Coverage includes Chinese-only candidate commits, orientation changes, rapid mixed input, repeat deletion, password and numeric fields, and dark mode. The v2 APK signature, 16 KB alignment, three ABIs, dictionaries and third-party notices were checked.

Physical-device long-term use, OEM editor compatibility, frame rate, power use and modern vocabulary quality remain unverified. This public preview is signed with the Android development key; a dedicated key is needed before a production-stable release.
