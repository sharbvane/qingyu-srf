## 真实 Android SQLite 与候选质量

- `NINE_KEY_V065_CHECKS_PASS`、`NINE_KEY_V066_CHECKS_PASS`、`NINE_KEY_V067_CHECKS_PASS` 和 `ALL_INPUT_DICTIONARY_CHECKS_PASS` 通过。包含图头、数量、拼写、偏移、行号、负频率、截断等损坏数据拒绝检查。
- `773`、混合 `74873` / `7732`、完整 `7487832` 均首选「输入法」，原始数字消费长度和待输入字母保持一致。单字母连续选择 `n → i → h → a → o` 可组成「你好」；完整音节选择仍保留边界。
- 八个字母组检查全部大小写字母、数字及有效拼音；覆盖现代词、首字母、混拼、分词、部分选词和剩余约束。使用通用词库匹配，没有为示例写别名或补权重。
- 组合 `w'y'k'd's'p` 可产生完整「我要看短视频」，本轮数据检查中位于第 8 项，不能宣称所有整句简拼均首位命中。未约束 `kfxm` / `sjsrf` / `mthj` 的目标分别位于第 7 / 2 / 2 项；短码重码可继续选择字母或音节。
- 个性化 `kd → 快点`：第一次选择仍为第 16 项，12 次后升至第 2 项，关闭重开保持；新短语、分段选词后的完整短语学习、禁用学习的字节保持检查通过。旧学习文件名和格式未更换。另模拟 100 次高频「快点」习惯，仍可产生「我要看短视频」；单独九键 `53` 配合 `k'd` 的「快点」保持前列。整句内部限制无关短词的全局加权，上下文学习仍参与排序。
- 200 次预热九键查询共 1208.00 ms；九键图加载 155.76 ms，未约束整句冷查询约 11.37–198.86 ms。这些是模拟器批量查询数据，不是手机按键延迟或帧率承诺。快速连打只省去过期候选计算，所有按键与提交动作按顺序保留。

## 实际键盘回归

- 最终正式 APK 在 API 35 / x86_64 / 4KB 页 / 字体 1.0 通过 `ImeV67Instrumentation` 全部 24 组检查；同一包在官方 `google_apis_ps16k` / 实测 16384 字节页 / 字体 1.3 再次通过全部 24 组，结束后恢复字体 1.0。
- 保留 17 组旧九键检查，覆盖布局、实时拼音、部分选词、分词、清空、确认、长按大小写及数字、取消、模式切换、英文、全拼回车、连续退格、深色、旋转、密码输入和可滚动音节侧栏。
- 新检查覆盖 ABC 全部七项、`773 → 输入法` 首位、单字母拼成音节、全拼/简拼/混拼、整句简拼确认、字面字符保留未选尾部及回退、分词键数字 1 的长按松手及取消。两种环境均保留原始编码，不提前提交。
- 侧栏重排后用拼写保持无障碍节点标识，旧节点不会误选别的字母；选段变化清除过期候选，避免旧候选可见但点击无效。数据查询及图加载仍在后台进行。
- 同源 Debug 包通过全部 25 组九键检查，增加真实触摸与无障碍组件检查：旧字母节点随重排仍选择原字母，已移除的字母和回退节点拒绝旧操作；分词键数字 1 的松手、取消、模式切换及原有手势均通过。该包仅用于测试，不作为发布 APK。
- 最终正式 APK 在 4KB 环境通过基础输入全部 17 组检查，包括长句、候选展开滚动、快速中英数字切换、70 字连续输入、连续退格、旋转、光标、密码、数字字段及深色重启。
- 同一最终正式 APK 在 16KB 环境通过 `ImeV6Instrumentation` 全部 56 组检查：现代全拼词、整句排序、误触纠错、12 次 `kd` 学习、40 次连续输入/选择/删除、12 次切换到系统设置并返回、预测上限、候选和导航、文本编辑与剪贴板均正常。
- 六种模型均显示就绪及实测安装大小；日语、法语、德语、俄语、西班牙语的候选释义、详情与上滑译文一致。日语和德语删除后重新下载成功，删除期间中文输入继续可用。普通候选及展开区无品牌栏，详情保留模型来源。下载使用可访问官方模型服务的网络；此结果不代表所有手机或网络均可下载。
