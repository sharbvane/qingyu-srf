# 轻语输入法 · Android 首版产品规格

版本：MVP 规格，2026-10-04。本文描述产品目标、行为契约与验收标准；“目标”不表示性能或真机长期使用已经通过。实际交付范围、测试结果和已知限制应以发布说明为准。

## 产品定位与优先级

轻语首先是一款可作为 Android 默认输入法使用的中文键盘。用户自然输入拼音、选择中文候选；中文候选上方显示较小的英文词义，点击后只输入中文。示例：`kaifa` 显示“开发”，其上方为 `develop`，点击实际提交“开发”。译词不会自动提交，不改变候选排序，不要求学习操作。

优先顺序：输入正确与稳定 → 按键/候选响应 → UI 跟手与编辑兼容 → 中文候选质量 → 简洁视觉 → 英文辅助信息。任何翻译查词、缓存、加载或失败均不能阻塞中文按键或提交。

首版只支持中文到英文。将来日语、韩语、西班牙语等按学习语言 provider 替换，一次只显示一种辅助语言。翻译与中文引擎的词频、解析、排序独立。

## 首版必须覆盖的正常输入

| 功能 | 行为与验收 |
| --- | --- |
| 系统 IME | 安装后可从系统启用与选择，提供引导页面和设置，第三方应用可正常唤起 |
| 全拼中文 | 连续输入字母与拼音分隔符，展示真实引擎候选；可以分段选词与整句提交 |
| 候选选择 | 点击候选只提交对应中文；空格选择首候选；候选 ID 与当前快照一致 |
| 候选翻页/展开 | 横向候选切换与展开面板，保持中文和译词对应；收起后回到键盘 |
| 中文标点 | 中文模式常用逗号、句号、问号、感叹号及符号面板；标点提交前正确处理组合串 |
| 英文 | 中英切换、大小写/锁定大写、空格、英文符号、回车；英文模式字母立即输入 |
| 数字 | 数字与符号布局；按编辑器类型自动提供适合的数字/电话布局 |
| 中英混输 | 同一输入框中可交替输入中文、英文、数字；支持保留拼音原文/ASCII 输入，避免吞字 |
| 连续退格 | 按住连续删除，抬手或取消后立即停止；有组合串时先删编码，空编码时删编辑器文本 |
| 长按 | 基础按键长按符号/数字与连续删除，反馈轻量；取消手势时不误触提交 |
| 滑动/光标 | 空格左右滑动移动光标；候选滑动浏览；滑动结束不追加误点击 |
| 深色模式 | 跟随系统与基础主题设置；两种主题均保持中文优先的清晰层级 |
| 设置 | 译词显示、主题、震动、键盘高度等必要选项；默认值适合初次安装 |
| 英文注释 | 本地查询为主、未命中留空、异步补充；关闭后不查词，中文行为保持一致 |

MVP 不加入账号、社区、广告、学习任务、每日打卡、表情商店、云翻译、语音或大型模型。候选准确率靠成熟解码器、真实词库与用户学习逐步改善，不把功能数量当成成熟度。

## 候选栏与视觉约束

- 中文为第一层级；英文为第二层级，字号更小、颜色更弱、单行省略。
- 候选中文长度决定候选单元的宽度；英文更新不改变单元宽度与整体栏高。
- 显示开启时预留固定注释行。词典未载入或无释义时该行留空，不显示加载 spinner。
- 按键与候选的触摸面积需覆盖视觉区域，足够容错；候选展开入口固定、可预测。
- 主键盘只保留输入所需功能。主题以干净的中性色与少量强调色表达按下/选中状态，拥有自己的名字、图标与布局细节。
- 动画只辅助状态反馈，避免候选每次刷新淡入、位移或动态拉伸；按下立即反馈，抬手迅速恢复。
- 横屏减少占屏高度、重新计算触摸布局。长按弹层与候选面板不得被导航栏或屏幕边界遮挡。

用户截图体现“中文候选附带英文”的信息结构；其中荧光绿品牌、文字、图标与特定滑动译文功能不是本项目 UI 规范。

## 输入与译词的线程模型

1. 主线程立即处理触摸状态与按键视觉，不能在绘制或 touch handler 中打开字典或访问磁盘。
2. 中文输入事件按顺序提交给单一引擎 worker；引擎产出不可变快照后立即交给候选绘制。
3. 翻译 worker 查询当前快照的有限候选批次（首版至多 128 项），使用本地索引与内存缓存；它不持有中文引擎锁。后续可优化为仅查询屏幕可见候选。
4. 每份快照带会话/请求版本。翻译完成后仅在版本和候选身份匹配时补充 annotation，旧结果直接丢弃。
5. 提交文本使用用户选择时的候选与引擎状态；不能因异步重排或过期 UI index 提交别的词。
6. 关闭译词时取消或作废在途查询，清除显示。加载失败、查不到、异常不展示阻塞弹窗。

键盘开启时只初始化必需组件；中文词典预热与翻译数据库分别管理。用户词频落盘在服务/会话的合适边界执行，不逐键同步写磁盘。缓存限制容量，关闭服务时释放数据库、回调与 worker。

## 系统编辑行为

Android service 适配 `EditorInfo` 的输入类型与 Enter action（发送、搜索、完成、下一项、换行）。组合串通过 `setComposingText` 展示，只有真实提交才调用 `commitText`；用户在宿主应用手动移动光标、切换焦点、切换应用时需协调组合状态。

密码字段关闭用户学习与译词，固定直接输入。系统 NO_PERSONALIZED_LEARNING 标志关闭用户学习，同时保留正常中文输入和可选释义。首版不声明网络权限，不上传按键或上下文，不保存用户输入日志。删除优先处理当前选择区；普通删除避免 UTF-16 半个代理字符，包含 emoji 的输入框需要专项验证。[Android IME 指南](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method)、[InputConnection 参考](https://developer.android.com/reference/android/view/inputmethod/InputConnection)

空格滑动光标属于文本编辑手势。组合串存在时必须先采用明确的结束/保留策略，不能让平台光标与引擎光标静默分叉。抬手、`ACTION_CANCEL`、窗口隐藏和服务销毁均应停止重复删除与长按任务。

## 数据与跨平台边界

当前结构：`core/` 为纯 Java 候选/快照/引擎契约与译词接口；`app/` 为 Android 服务、触摸 UI、设置、SQLite provider、JNI 与打包；`third_party/` 记录第三方来源和许可证；`tools/` 保存可重现构建与数据转换；`releases/` 为可安装 APK 与说明。

翻译数据按源语言/目标语言/版本组织，键为完整中文候选词。后续 provider 实现可换成 zh-ja/zh-ko/zh-es，UI 不写死“英文”算法。首版保留本地 SQLite 的清晰许可与生成过程。词典释义不承担整句翻译职责，多义词的短释义作为辅助，需要后续人工质量抽样。

iOS 阶段重用词典数据格式、引擎边界、会话和注释协议，平台文本适配使用 `UIInputViewController` 与 `textDocumentProxy`。现有 Java module 并非 iOS 可直接加载库；必要时通过原生 C ABI 提取共同核心。iOS 的安全输入与应用限制须遵守平台行为，提供下一键盘键。[Apple 自定义键盘指南](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/CustomKeyboard.html)

## 性能目标与记录方式

以下为待测工程目标，发布说明必须写设备/系统/构建类型与测量方法，不能用编译成功替代数据。

| 指标 | 第一阶段建议目标 | 记录方式 |
| --- | --- | --- |
| 按下到视觉反馈 | 下一帧内产生反馈 | 触摸事件时间与 UI frame trace |
| 热状态中文候选生成 | p95 ≤ 30 ms | 引擎 worker 耗时与排队时间分别记录 |
| 输入到候选显示 | p95 ≤ 50 ms | 按键序号至对应候选快照完成显示 |
| 热状态键盘弹出 | p95 ≤ 200 ms | onStartInputView 至首帧 |
| 首次启用 | 键盘先显示、字典后台就绪 | 首装/冷启动分开记录 |
| 动画与滑动 | 目标保持设备刷新率，无周期性卡顿 | frame metrics / Perfetto；60/120 Hz 分开 |
| 内存与稳定性 | 长时使用不持续增长、不 ANR | 长时轮测、内存前后对照与崩溃记录 |
| 翻译失败隔离 | 中文响应与提交不受影响 | 字典不可用、空结果、延迟、异常注入 |

不要为提速丢弃按键、删除、选择与提交事件。高频候选渲染或过期译词请求可以合并，输入语义事件必须可靠有序。

## 安装体验与验收场景

首次打开显示简洁启用流程：打开系统输入法设置 → 用户启用轻语 → 打开系统选择器 → 在试打文本框体验。正常 Android 授权与输入法选择由用户操作；应用不绕过系统确认。设置页给出离线说明、基础手势提示与可读第三方声明。

发布 APK 必须完成构建、签名验证、安装包结构/ABI 检查与引擎测试。真机验收另行记录，不把未连接设备的情况写成“日常主力验证通过”。建议依次执行：

1. 普通输入：`nihao`、`kaifa`、`xiangmu`、`biancheng`、`bushu`、`sheji`，正确选词，只提交中文。
2. 分段输入：长拼音句，先选择短候选，再完成余下拼音；反复撤销/删除不吞字符。
3. 混输：输入“今天 review 项目 v1.0”，切换英文、数字、中文不改写已提交文本。
4. 候选：滑动、展开、翻页、收起、快速选择；译词更新前后位置稳定，候选与词义一致。
5. 高速压力：连续输入与退格、长按取消、多指触摸、删除至空文本，观察丢字/重复/卡顿。
6. 编辑兼容：聊天、浏览器、搜索、便签、密码、URL、数字、电话输入框；Enter action 正确。
7. 生命周期：快速切换应用/输入法、横竖屏、深浅主题、锁屏/后台后重启，不残留旧候选。
8. 翻译隔离：关闭开关、查不到词、词典不可用、迟到结果；中文候选与实际提交正常。
9. 长时使用：实际手机连续日常使用并抽样词库质量、耗电、内存与故障，再判定是否可长期替代主力输入法。

首版成功交付物是可实际安装使用的 APK 与完整可重现工程。长期使用是否达标需真实设备和真实应用的持续反馈，优先修输入问题，再扩大译词覆盖和语言种类。
