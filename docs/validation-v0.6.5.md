# 轻语输入法 v0.6.5 验证记录

日期：2026-10-08。基于既有 v0.6.0（e8b8bb5）迭代，沿用项目、正式签名、词库和墨绿色主题。测试设备为本项目的 Android 15 / API 35、x86_64、1080×2340 无窗口模拟器 Qingyu_API35；没有操作用户真机。

最终 APK 已发布在 [GitHub Release v0.6.5](https://github.com/sharbvane/qingyu-srf/releases/tag/v0.6.5)，版本代码 7、Android 8.0+、目标 API 35，96,441,001 字节，比 v0.6.0 增加 16,384 字节。SHA-256：`4ca091fae2ad3a180a40fe98e1e14ed0dbc81338a72962e53c251c7e82079ace`。下表的正式包 UI 检查和包审计都对应这个最终 SHA。

## 本轮实现范围

- 九键字母组仍传递 2–9 编码给后台解码器，编辑器实际预编辑和贴边拼音浮层显示当前候选的拼音。候选读音按用户已输入的字母数量截取，未输入的补全字母不提前展示；没有可用候选时显示临时字母拼写，后台结果随后补充。等待下一键或删除结果时保留已解析的兼容前缀，避免整串拼音退回通用字母映射。
- 保留固定候选与键盘空间。三列字母组左侧是标点/读音侧栏，右侧为删除、清空和双行高确认；底部提供符号、中英切换、空格和数字模式。原来的候选展开、翻译、预测和导航继续复用。
- 「分词」键支持九键明确音节边界，候选过滤尊重边界；候选消耗长度包含对应分隔符，分段选词不会丢失后续按键。清空只取消当前预编辑，不删除已经提交的内容。九键确认提交中文候选，全拼回车继续提交原始拼音。
- 长按字母组弹出两行大小写选项和一列数字，滑动显示选中项，松手输入一次；取消、多指打断及模式切换丢弃待选字符。普通点击字母组仍进入拼音。保留全键盘原有长按交互，并给九键浮层提供可访问选项及直接字符无障碍操作。
- 复用当前现代词库，追加有预算的两音节九键查询，补充九键等常用短词；没有新增词库文件、依赖或默认翻译模型，现有学习文件名称和格式保持一致。

## 签名与覆盖升级

首个 v0.6.5 正式构建已从原始 v0.6.0 系统覆盖安装。应用 UID、私有偏好/哨兵、原生用户词典和三个学习文件的字节摘要保留。随后修正了九键已解析前缀的临时显示和测试夹具；最终包继续使用同一签名体系并反复通过 `adb install -r`，全部 UI 回归针对最终包。

正式证书 SHA-256：`1d6872a840fe42468cdc5af2d11eeee87455c4b635e2fd2b60168b082c4e0cf5`。API 28+ 保留经过认证的旧签名→正式签名历史，API 26–27 延续兼容签名。没有生成新密钥或改变备份体系；不要卸载后再安装以免丢失本机学习记录。

## 中间失败及处理

1. 首轮九键夹具尝试通过可访问节点读取非触摸、非聚焦的拼音 PopupWindow。Android 不将它暴露在窗口清单，实际截图和编辑器已正确显示 jiu'lian。夹具改为候选宿主可访问描述与真实 composing span 一致性检查，并保留实际截图人工检查。没有添加生产测试钩子。
2. 首轮既有 v0.6 回归误用「模型未安装」分支，但复用的模拟器已经安装日语模型，上滑实际成功提交译文，未弹出「未下载」详情。按真实已安装前提以 `-ModelsAvailable` 重新执行，完整 56 组通过，没有为夹具改变翻译行为。

## 视觉检查和已知限制

本地 QA 截图覆盖空闲布局、拼音与读音侧栏、字母浮层、深色和横屏。候选/释义在固定区内、贴边拼音相连、绿色确认清晰；本轮按 Impeccable 的原生操作界面原则检查，原生 Canvas 几何采用实际截图与 MotionEvent 检查，网页布局扫描器不适用于此控件。截图保存在构建机忽略的 QA 目录，未作为项目文件发布。

- 未验证真机单手滑选、震动、触控帧率/功耗、OEM 生命周期、真实 16KB ARM64 或长期输入。横屏沿用既有紧凑高度，实际手指目标尺寸仍需真机反馈。
- 九键有多个合法读音。同一组合 5485426 可对应就连、六角、九键等；自动显示当前最优候选读音，侧栏与分词辅助用户调整。现代短词补充限制为 4–12 位、两音节、最多 32 组索引查询和 256 组缓存；更长九键串沿用已有有界组词。复杂长句仍有排序缺口，见 [v0.6 验证记录](validation-v0.6.0.md)。
- 普通点击确认/空格结束拼音，长按选出的字母/数字直接上屏；若已有拼音，先按既有结束逻辑提交当前内容，再输入明确选中的字符。
- 沿用现有 ARM64 大于 4KB 页大小的官方模型安全降级。本轮没有新增默认外语模型；模型下载需能访问官方服务，模拟器测试临时使用项目已有本机代理，测试后撤销模拟器代理。模型译文可能不准确。
- 打字和展开列表继续不显示 Google 品牌标识，详情保留来源。与官方相邻来源展示要求的差异继续记录于 [SDK 说明](../third_party/mlkit/SOURCE.md)，本报告没有宣称满足该来源展示要求。
- 本版本已发布至 [GitHub Release v0.6.5](https://github.com/sharbvane/qingyu-srf/releases/tag/v0.6.5)。本轮未验证真机安装、真机单手触控、震动、触控帧率/功耗、OEM 生命周期或长期输入。
