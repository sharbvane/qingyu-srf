# 轻语输入法 v0.4.0

安装 [Qingyu-0.4.0.apk](Qingyu-0.4.0.apk)，与 v0.3 使用相同体验签名，可直接覆盖，无需卸载。Android 8.0+，包含 arm64-v8a、armeabi-v7a、x86_64。

- 59,836,541 字节（57.06 MiB），比 v0.3 增加 16,596 字节（0.03%）；默认仍只内置中英文资源。
- SHA256：`24634AA1D406AF73D1FF23DCFB42947473DDA6FB0BBD791751112233F18B9BDC`。
- 空闲时紧凑空候选栏加导航，输入时候选区替代导航；原始拼音从左上边缘贴合凸出，回车提交原始字母。
- 展开候选上下连续滚动；更多增加应用内更新与项目主页。
- 德语、俄语、西班牙语释义按需下载，保留英语、日语、法语；可查看实际容量、删除或重新下载。删除清理 SDK 遗留的解包文件。

建议先测试中文拼音回车、分段选词、候选展开滚动、空闲/输入顶部切换，再体验新增语言与更新入口。保留已有九键、英文候选、预测、剪贴板、大小写和长按滑动。

使用方法见[安装说明](https://github.com/sharbvane/qingyu-srf/blob/main/releases/%E5%AE%89%E8%A3%85%E8%AF%B4%E6%98%8E.md)，实际检查与限制见[v0.4 验证记录](https://github.com/sharbvane/qingyu-srf/blob/main/docs/validation-v0.4.0.md)。正式版已发布：[GitHub Release v0.4.0](https://github.com/sharbvane/qingyu-srf/releases/tag/v0.4.0)。也可直接[下载 APK](https://github.com/sharbvane/qingyu-srf/releases/download/v0.4.0/Qingyu-0.4.0.apk)和[校验文件](https://github.com/sharbvane/qingyu-srf/releases/download/v0.4.0/Qingyu-0.4.0.apk.sha256)。
