# 轻语输入法 v0.5.0 安装说明

正式包 [Qingyu-0.5.0.apk](Qingyu-0.5.0.apk) 已通过静态审计、API 35 模拟器数据保留覆盖升级、53 项完整输入法回归、17 项基础输入及字体 1.3 倍的 14 项专项检查。Android 8.0+；本版现已发布到 GitHub Releases；原 v0.4 APK 保留。

安装包 93,684,139 字节，约 93.7 MB / 89.34 MiB；SHA-256：`76D70841DA75BF54FF4C65865B1F415F53E2D843E162E978EEDA40453882102B`，附[校验文件](Qingyu-0.5.0.apk.sha256)。现代中文词库扩充使 APK 从 v0.4 的约 59.8 MB 增至约 93.7 MB；没有预装额外外语翻译模型。

将正式 APK 发送到手机，点开并按 Android 系统提示**直接覆盖安装，保留旧应用，不先卸载**。v0.4 的旧更新器不能识别首次 Release 证书轮换，第一次升至 v0.5 使用本地 APK；以后继续使用稳定 Release 签名与应用内更新。证书兼容、长期保存和备份方法见[正式签名说明](../docs/release-signing.md)。

本轮重点提升中文常用词、拼音歧义与轻微误拼候选，保留原始字母回车和现有候选交互。`kd → 快点`及分段句可通过重复选择逐渐学习；新增错拼别名和组合短语需累计至少 3 次才成为直接候选。键盘与展开列表保留本地中英释义，模型翻译在带来源说明的详情页查看、确认输入。

建议安装后测试 `anzhuo`、`dangang`，以及日常长句、候选展开、连续删除和跨 App 返回。未学习的“请扫码支付”“我想打网约车”“我要看短视频”仍有语义排序缺口；模拟器通过不代表真机长期稳定性。完整已测范围、原始报告与未完成项见[v0.5 验证记录](../docs/validation-v0.5.0.md)。
