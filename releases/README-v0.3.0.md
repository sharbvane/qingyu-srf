# 轻语输入法 v0.3.0

安装 `Qingyu-0.3.0.apk`。与 v0.2 使用相同体验签名，可直接覆盖安装；Android 8.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64。

- 大小：59,819,945 字节（57.05 MiB），比 v0.2 减少 3.30%。
- SHA256：`363D182A1B498FAEA8E1DA0F97D77D6FD11CDE25A2C020EE27E3CF287EB3F4E0`。
- 固定候选空间、候选展开恢复、最多三轮预测及「X」清空。
- 中文 Shift 临时大写/大写锁定，字母长按后滑动选择大小写或数字。
- 同一导航图标展开/收起面板，轻量过渡和低饱和中文词性配色。
- 默认仅内置中英资源；在「设置 → 翻译模型管理」按需下载、删除日语或法语模型。下载需 Wi-Fi，未下载时仍可正常输入中文和英文。

安装后打开轻语，按系统提示启用并切换输入法。建议测试 `kaifa`、`xiangmu`、九键、Shift、长按左右滑动、预测「X」及候选展开；上滑候选输入译文，长按查看完整释义。

实际检查和范围见 [v0.3.0 验证记录](../docs/validation-v0.3.0.md)。本轮使用 Android 15 模拟器，真机触摸、震动手感和长期使用仍需安装体验。
