# 轻语输入法 v0.6.0 安装说明

本轮继续 v0.5 项目，重点改善连续拼音、渐进学习和多语言释义，保持已有简洁键盘。**v0.6.0 正式版现已发布至 [GitHub Release](https://github.com/sharbvane/qingyu-srf/releases/tag/v0.6.0)。** Android 8.0+，从 [此处下载 APK](https://github.com/sharbvane/qingyu-srf/releases/download/v0.6.0/Qingyu-0.6.0.apk)。

安装包 96,424,617 字节，约 96.4 MB / 91.96 MiB；SHA-256 `65b781d1cda76352857e6d171b6d7c8e67e8a40f46c1ab2d181bc443112c83db`；[校验文件](https://github.com/sharbvane/qingyu-srf/releases/download/v0.6.0/Qingyu-0.6.0.apk.sha256)。较 v0.5 增加 2,740,478 字节 / 2.93%，主要来自约 2.7 MB 的中文上下文资源，没有预装日、法、德、俄、西等额外翻译模型。

将正式 APK 发送到手机，按系统提示直接覆盖安装，**保留旧应用，不先卸载**。继续使用 v0.5 正式签名；实际模拟器 v0.5 → 上述 v0.6 包覆盖检查已确认 UID、设置、中文和英文学习记录及原生用户词库保持。签名保存与恢复见[签名说明](../docs/release-signing.md)。

中文全拼左下为「分词」，插入拼音分隔；英文模式仍为 Shift。回车输入原始拼音。候选栏先显示中文，本地释义及已安装模型异步补充；长按查看完整释义，上滑直接输入当前语言的简洁译文。展开后上下浏览，长句和翻译完整换行。普通候选与展开列表不显示 `powered by Google Translate`，模型详情保留来源标识。

英语、日语、法语、德语、俄语及西班牙语可在「更多 → 释义显示语言」选择。额外模型按需下载，普通打字不下载；模型管理显示真实进度、等待/失败原因、重试、已安装大小及删除，默认 Wi-Fi，移动数据须明确允许。未下载时不预占对应模型存储，基本中文和英文输入不受影响；下载需能访问官方模型服务。

建议安装后测试 `woyaokanduanshipin`、`anzhuo`、`dangang`，以及手动分词、原始拼音回车、长句展开、语言切换与上滑译文、模型下载/重试。`kd → 快点` 可通过长期选择逐步前移，单次误选不会立即成为强候选。

未完成真机长期稳定性、触控帧率/功耗和 16 KiB ARM64 实机验证；此类 ARM64 设备继续禁用官方模型功能，本地中文输入与中英释义可用。复杂连续拼音仍有排序缺口，译文也可能不准确。中间失败、已测范围和已知限制见[完整验证记录](../docs/validation-v0.6.0.md)。
