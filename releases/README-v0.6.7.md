# 轻语输入法 v0.6.7

本轮重点修复九键解码与词库匹配，保留现有墨绿色布局、中文全拼、英文与候选翻译交互。

- 九键支持全拼、首字母简拼及混合拼音，覆盖现有现代词库，不针对单个示例补词。输入 `773`，首选「输入法」。短码重码时可以继续选字母或完整音节。
- 左侧栏显示当前按键的全部大小写字母、数字和有效音节，可上下滚动。ABC 提供 `A、B、C、a、b、c、2`。小写字母和音节用于拼音选择；大写及数字作为明确的字面内容保留在待输入文本中，确认后上屏。
- 单字母可连续组成完整音节，也可作为简拼；选中后自动进入下一段，候选实时同步。回退可恢复上一选择及原始按键，不丢掉剩余输入，不提前提交。
- 侧栏重排保持选项标识稳定，防止连续选择时旧位置误选另一字母；选段变化立即清除过期候选，避免旧候选显示期间点击无效。
- 分词键右上角显示 `1`。短按仍执行拼音分词；长按滑选数字 `1`，松手输入，取消不输入。原字母组长按滑选保持不变。
- 长句组词结合本地词频、语料上下文和已有个人习惯。完整匹配优先于未完成拼音补全；快速连打时省去过期候选计算，所有按键仍按顺序处理。
- 键盘和展开列表继续不显示 Google 品牌栏。六种释义语言与按需模型下载功能保留。
