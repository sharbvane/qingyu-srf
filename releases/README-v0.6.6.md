# 轻语输入法 v0.6.6

本轮优化九键拼音选择和翻译模型兼容性，保留现有墨绿色主题、全拼、英文、候选及翻译交互。

- 左侧拼音栏支持上下滚动，显示全部可用读音，不再截取前四项。
- 选择一个音节后自动进入下一音节；已选拼音、候选及翻译保持同步，整段输入仍待选，不提前上屏。左上角回退按钮可修改上一音节；音节全部选完时，退格先撤销最后一次选择。只有选词或确认才提交中文。
- 修正 16KB ARM64 设备被统一判为不支持模型的问题。后台检查安装包内官方模型库的真实布局，通过安全检查后开放下载和翻译；异常或不兼容布局仍安全降级。未修改官方模型二进制，也未增加云端文本翻译。
- 保留六种释义语言的按需下载、真实进度、失败提示和重试，以及九键长按滑选大小写字母与数字。普通键盘和展开候选继续不显示 Google 品牌栏。

在「键盘模式 → 中文 · 九键拼音」输入 `64426744543`，依次选择 `ni → hao → shi → jie`，可从候选输入「你好世界」。选择读音期间可回退重选；输入 `7426` 可上下滑动查看不同读音。
