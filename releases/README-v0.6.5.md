# 轻语输入法 v0.6.5 · 九键优化版

安装包：[从 GitHub 下载 Qingyu-0.6.5.apk](https://github.com/sharbvane/qingyu-srf/releases/download/v0.6.5/Qingyu-0.6.5.apk)。Android 8.0 及以上，正式 Release 签名、版本代码 7。可直接覆盖 v0.6.0，建议保留原应用，不要卸载后重新安装。

本轮保留墨绿色主题与现有全拼、英文、候选和翻译交互，集中调整九键：

- 九键预编辑显示候选对应的拼音，随按键和选词动态更新；短暂等待解码时保留已经解析的拼音前缀，避免整串字母回跳。分段选词保留已选中文与剩余拼音。
- 三列字母组配合左侧标点或拼音读音选择；右侧是删除、清空与双行高确认键。底部独立提供符号、中英切换、空格和数字模式。分词键可明确加入音节边界，确认提交当前中文候选；全拼回车仍提交原始拼音。
- 长按九键字母组出现大小写字母和数字浮层。滑动高亮，松手输入所选单个字符；取消、切换模式不输入。选出的字母和数字直接上屏，不进入中文拼音。
- 复用已有现代拼音数据库补充短词九键匹配，没有新词库文件或模型进入默认 APK。打字和展开候选不显示 Google 品牌栏。

请在「键盘模式 → 中文 · 九键拼音」体验：64426 → ni'hao → 你好；5485426 可在左侧选择 jiu，再从候选中选择九键；64 → 分词 → 426 可以选择你好；长按 ABC 滑到 C、b 或 2，再松手输入。
