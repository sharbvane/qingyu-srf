# 轻语输入法 0.1.0

安装 **Qingyu-0.1.0.apk**，打开轻语，依次点「启用轻语输入法」和「切换到轻语」。
Android 8.0 及以上；包含 arm64-v8a、armeabi-v7a 和 x86_64。

先试 `kaifa`、`xiangmu`、`sheji`。英文在候选上方，点候选只输入中文。
「中 / EN」切换中英文；`?123` 打开数字与符号，`#+=` 打开第二符号页。
空格左右滑动移动光标，长按退格连续删除，长按第一排字母输入数字。
长按中文逗号输入隔音符，例 `xi'an` → 西安。
候选左右滑动；右上角展开后可以翻页选词。EN 按钮可关闭英文释义。
设置内有深色/浅色/跟随系统、震动、按键预览、键盘高度、词频开关。

这是首版 MVP，已进行模拟器自动化与中文引擎压力测试；尚未进行真机长期使用。
旧版 AOSP 词库对于新词和网络词覆盖有限，复杂语境的首候选仍需继续优化。
释义来自本地词典，表示常见义；没有释义会留空，不进行云翻译。

完整测试范围与结果：`../docs/validation.md`。
完整源码、研究、许可证和可复现构建脚本均在项目目录内。
