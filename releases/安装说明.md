# 轻语输入法 0.2.0

安装 **Qingyu-0.2.0.apk**。可直接覆盖前版，无需卸载。Android 8.0 及以上，支持 arm64-v8a、armeabi-v7a、x86_64。

打开轻语，依次点「启用轻语输入法」和「切换到轻语」。先试 `kaifa`、`xiangmu` 或 `sheji`。

- 顶部五个图标为：更多、文本编辑、Emoji、键盘模式、收起。
- 「更多」可调整释义语言、设置、键盘高度、风格和震动。高度滑条连续调节。
- 「键盘模式」切换中文全键拼音、中文九键或 English。九键输入 `52432` 可选「开发」；长按数字键直接输入数字。
- 候选单击输入原词，长按查看完整释义，上滑输入译文。候选列表末尾的箭头展开候选；预测候选不显示展开箭头。
- 英文 `hel` 可选 hello；选入后显示 world 等续词。空格不会擅自改正输入的拼写。
- 文本编辑提供选择、全选、复制、剪切、粘贴和最近 100 条剪贴板历史。长按历史条目删除；「清空历史」立即清空。
- 空格左右滑动移动光标，长按退格连续删除。`?123` 打开数字/符号，`#+=` 切换符号页。

中文候选可显示英语、日语、法语释义；英文候选默认显示中文释义。常用词和短语随包提供。更广的句子翻译需要在「更多 → 释义显示语言 → 下载离线模型」连接 Wi-Fi 主动下载。模型未下载时，有些释义会留空，上滑会提示模型状态；点击原候选仍正常输入。

首次模型下载需要网络能够连接 Google 模型下载服务。下载完成后可断网翻译，已在模拟器断网条件下验证。APK 约 59 MiB，模型文件会额外占用存储。

输入和译文在本机处理，不调用云端文本翻译。Google SDK 有模型、配置和诊断网络请求，会发送设备/安装、语言、长度和性能元数据；不发送输入或译文原文。详情见项目 `third_party/mlkit/SOURCE.md`。剪贴板不上传，可在设置关闭记录；敏感剪贴板及密码字段不留历史。

这是一版体验版。已执行的检查见项目 `docs/validation-v0.2.0.md`；真机长期使用、厂商编辑器兼容性、震动与手感尚待实测。源码、来源和可复现构建脚本均在项目目录内。

16KB 内存页的 ARM64 设备暂不加载官方模型，以避免其原生库对齐问题影响输入；仍可使用正常键盘、本地词典和三语常用短语，面板会提示状态。
