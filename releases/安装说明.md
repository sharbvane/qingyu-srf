# 轻语输入法 0.5.0

安装 **Qingyu-0.5.0.apk**。首次从 v0.4 升级请打开本地 APK，通过系统安装器直接覆盖，无需卸载。Android 8.0 及以上，支持 arm64-v8a、armeabi-v7a、x86_64。

打开轻语，依次点「启用轻语输入法」和「切换到轻语」。先试 `anzhuo`（安卓）、`dangang`（单杠）、`nohao`（纠错候选“你好”），或原有 `kaifa`、`xiangmu`。常选的全拼、简拼和分段短语会在开启个性化学习后逐渐前移。

- 未输入时保留紧凑空候选栏与五个导航图标；开始输入后候选区替代导航，原始拼音紧贴键盘左上边缘凸出显示，结束后恢复导航。按键位置保持固定。
- 顶部五个图标为：更多、文本编辑、Emoji、键盘模式、收起。再次点击同一面板图标直接收起。
- 「更多」可调整释义语言、设置、键盘高度、风格和震动，还可检查更新、打开 GitHub 项目主页。高度滑条连续调节。
- 「键盘模式」切换中文全键拼音、中文九键或 English。九键输入 `52432` 可选「开发」；长按数字键直接输入数字。
- 中文全拼输入中，回车直接提交原始拼音字母；空格和候选点击仍按正常中文输入规则处理。
- 候选单击输入原词，长按查看完整释义；候选栏上滑时，本地释义直接输入，模型译文打开详情并明确确认后输入。候选列表末尾的箭头展开候选，展开列表可上下连续滑动；在展开列表长按释义页输入译文，避免与纵向浏览冲突。预测候选不显示展开箭头。
- 英文 `hel` 可选 hello；选入后显示 world 等续词。空格不会擅自改正输入的拼写。
- 下一词预测最多连续选入三轮；预测行右侧「X」立即清空，手动输入后恢复候选。
- 中文全拼默认小写拼音；Shift 点一次输入一个大写英文字母，快速双击锁定大写，再点关闭。大写字母直接上屏。
- 普通字母长按后左滑选大写、右滑选小写；带数字的字母长按后左侧大写、中间小写、右侧数字。松手输入选中的字符。
- 文本编辑提供选择、全选、复制、剪切、粘贴和最近 100 条剪贴板历史。长按历史条目删除；「清空历史」立即清空。
- 空格左右滑动移动光标，长按退格连续删除。`?123` 打开数字/符号，`#+=` 切换符号页。

默认只内置中英文输入和释义资源。键盘和展开列表只显示本地词典释义，英文候选默认显示本地中文释义；不显示 Google 品牌栏或模型译文。英语、日语、法语、德语、俄语、西班牙语的模型翻译在带来源说明的详情页查看，确认后可输入。额外模型按需下载，可在「翻译模型管理」查看状态、实际占用、删除及重新下载。更广的英语整句翻译也可在该页面下载中文共享模型。下载需 Wi-Fi；模型未下载时提示状态，点击原候选仍正常输入。

首次模型下载需要网络能够连接 Google 模型下载服务。下载后推理在本机完成。APK 为 89.34 MiB，本轮增长来自现代中文词库及索引，额外翻译模型仍不进入安装包，下载后才占用存储。

「检查更新」读取官方 GitHub Releases，发现更新时在应用内展示版本、更新说明和 APK 大小。下载完成后校验版本和签名，进入系统覆盖安装流程；首次需要允许轻语安装应用，随后由系统确认安装。v0.5.0 已发布至 [GitHub Releases](https://github.com/sharbvane/qingyu-srf/releases/tag/v0.5.0)，同版本不会提示更新；后续正式版本发布后，可在此处下载并进入系统覆盖安装流程。应用内更新支持 API 限流后的官方网页回退、缓存和退避；后续版本发布后可在应用内检查。网络失败可稍后重试。

输入和译文在本机处理，不调用云端文本翻译。Google SDK 有模型、配置和诊断网络请求，会发送设备/安装、语言、长度和性能元数据；不发送输入或译文原文。详情见项目 `third_party/mlkit/SOURCE.md`。剪贴板不上传，可在设置关闭记录；敏感剪贴板及密码字段不留历史。

已执行的检查及已知整句排序限制见项目 [v0.5 验证记录](../docs/validation-v0.5.0.md)；真机长期使用、厂商编辑器兼容性、震动与手感尚待实测。源码、来源和可复现构建脚本均在项目目录内。

16KB 内存页的 ARM64 设备暂不加载官方模型，以避免其原生库对齐问题影响输入；仍可使用正常键盘、本地中英词典和中英常用短语，面板会提示状态。
